##概要
現職のダンス教室では、体験者情報や対応状況を紙や口頭で管理しており、講師間での情報共有や引き継ぎ漏れが課題となっていました。

そこで、体験者情報や対応履歴を一括管理し、講師間でスムーズに情報共有できるWebアプリを開発しました。

本アプリでは、体験者情報の管理だけでなく、コメント機能や要確認機能を実装することで、担当講師以外でも対応状況を把握しやすい設計としています。また、生年月日から学年を自動算出する機能を実装し、学年更新の手間や入力ミスを防げるよう工夫しました。

Laravelを用いたWebアプリケーション開発を通して、実際の業務課題を意識した設計・実装に取り組みました。

## 制作背景
現職では、体験者への対応状況を紙のメモや口頭で共有しており、

・引き継ぎ漏れが発生しやすい
・誰がどこまで対応したか把握しづらい
・過去の対応履歴を確認しにくい

という課題がありました。

実際に現場で感じた課題を解決したいと考え、本アプリを企画・開発しました。

「現場で本当に使えるアプリ」を意識し、情報共有のしやすさや操作性を重視して設計しています。

## 工夫した点
学年はデータとして保存せず、生年月日から自動で算出する実装としました。
Laravelのアクセサ（getGradeAttribute）を利用することで、登録時は生年月日のみ入力すれば一覧画面では常に最新の学年が表示されるようにし、学年更新漏れを防げる設計にしました。

実際の業務では、講師ごとに勤務日が異なるため、業務引き継ぎを円滑にするため、他の講師へ連絡事項や未対応の事項を引き継ぐ場面が多くありました。
そのため要確認フラグを実装し、一覧画面からも確認状況を把握できるようにすることで、対応漏れを防げる設計としました。

体験者一人に対して複数回やり取りが発生することを想定し、コメントを別テーブルとして設計しました。1対多のリレーションを構築することで、対応履歴を時系列で管理できるようにし、過去の対応内容も確認しやすい構成としました。
