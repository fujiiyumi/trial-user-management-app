## 制作背景
現職のダンススクールでは、体験者情報を紙や口頭で管理しており、講師間での情報共有や引き継ぎ漏れが課題となっていました。

そこで、体験者情報や対応履歴を一元管理できるWebアプリを開発しました。

体験者ごとの対応状況やコメントを共有することで、講師間の情報共有を円滑にし、引き継ぎ漏れを防ぐことを目的としています。
